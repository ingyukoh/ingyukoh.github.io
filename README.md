# ingyukoh.github.io

Source for https://ingyukoh.github.io, a single static page with a portfolio of LangGraph agent work.

The featured project is [agentic-rag-eval](https://github.com/ingyukoh/agentic-rag-eval). Every metric on the page links to committed benchmark output in that repository.

No build step: GitHub Pages serves `index.html` as is.
