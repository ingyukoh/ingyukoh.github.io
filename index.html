SEC Filing RAG Auditor

A reproducible LangGraph agent that answers numeric questions over SEC 10-K facts. It plans, retrieves, grades metadata, verifies provenance, cites an SEC filing, and refuses to guess. It is benchmarked head-to-head against a single-pass baseline that uses the same corpus and retriever.

Where the baseline fails, and why

Every failure is committed to results/failures.md. The baseline misses 22 of 64 cases, and they fall into two patterns that the graph was designed to fix:

Failure patternCasesExampleGraph node that fixes it
Right company and metric, wrong fiscal year18aapl-2024-net-income → returned another year's valueplan extracts the year, then grade requires an exact match
Answered a question with no supporting fact4unanswerable-unknown-company → 391035000000verify abstains unless exactly one fact survives grading

Anti-tuning controls

  • Data comes from the official SEC EDGAR Company Facts API. Each fact stores CIK, XBRL concept, period, accession number, and archive URL.
  • data/manifest.json content-hashes the facts, questions, and provenance. If any of them change, tests fail before scoring.
  • The baseline and the agent share the same corpus and the same BM25 implementation. The only difference is orchestration.
  • CI runs ruff, pytest, and the full benchmark on Python 3.11 and 3.12.

Known limits

  • The corpus covers 3 issuers, 5 metrics, and fiscal years 2022–2025.
  • Planning is deterministic, which keeps the focus on orchestration and verification rather than on hosted-model quality.
  • The agent doesn't yet handle comparisons, ratios, or free-text accounting questions.
  • 100% applies only to this narrow benchmark. It is not a claim of production reliability.

Reproduce it in about a minute, offline

git clone https://github.com/ingyukoh/agentic-rag-eval && cd agentic-rag-eval
python -m venv .venv && source .venv/bin/activate
pip install -e '.[dev]'
ruff check . && pytest -q
python -m agentic_rag_eval.bench        # regenerates results/benchmark.md
docker compose up --build bench         # or run it without a local Python
